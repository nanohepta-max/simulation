# 返済計画 — ローン返済シミュレーター

複数の借入をまとめて管理し、変動金利の切替や繰上返済を反映して、返済期間・支払利息・月次の返済予定を確認できるブラウザアプリです。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 複数借入 | 借入ごとに元本・年利・返済期間・開始月を登録できます。 |
| 変動金利 | 指定月から適用する新しい年利を複数登録できます。金利切替時は残りの当初返済期間に合わせて通常返済額を再計算します。 |
| 繰上返済 | 月次の通常返済後に元本へ充当する**期間短縮型**として計算します。利息削減額と短縮月数を確認できます。 |
| 返済予定表 | 月々の返済額・利息・元金・繰上返済・残高を表示し、CSVで書き出せます。 |
| 保存・読込 | 計画をブラウザの端末内へ保存できます。JSON書き出し／読込によって端末間の移動やバックアップも可能です。 |
| 印刷 | 主要な結果と返済予定表を印刷できます。 |

## 計算上の前提

通常返済は**元利均等返済**です。金利切替が設定された月には、当該月の返済開始時点の残高と残りの当初返済期間を使い、新しい毎月返済額を算出します。繰上返済は通常返済後に元本へ充当し、通常返済額を原則維持することで完済時期を短縮します。

本アプリの結果は概算です。実際の金利適用日、端数処理、返済日、手数料、金融機関固有のルールなどにより、実際の請求額は異なる場合があります。契約内容と金融機関の返済予定表を必ず確認してください。

## ローカルでの実行

```bash
pnpm install
pnpm dev
```

開発サーバーの表示されたURLをブラウザで開いてください。
